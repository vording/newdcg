遊び方
  • 相手のライフ（初期20）を0にすれば勝ち。デッキが尽きてドローできなくなっても負け。
  • マナは毎ターン1ずつ増え（最大10）、ターン開始時に全回復する。
  • クリーチャーは出したターンは攻撃できない（速攻を除く）。攻撃したクリーチャーは行動済みになり、相手ターンにブロックできない。
  • 攻撃されたら、攻撃1体につき自分のクリーチャー1体でブロックできる。ブロックされると互いの攻撃力ぶんダメージを与え合う。
  • ダメージはターン終了時に回復する。そのターン中に倒し切ること。
  • 「対応」カードは、相手の攻撃宣言後・ブロック前にも使える（1枚まで）。マナを残してターンを終えよう。
  • 飛行＝飛行でしかブロックできない。先制＝戦闘で先にダメージを与える。警戒＝攻撃しても行動済みにならない。速攻＝出したターンに攻撃できる。
  • 後攻は開始時に「マナの雫」（0コスト：このターンマナ+1、1枚引く）を受け取る。
