# 自動テスト・調整レポート（v0.2）

AI同士の自動対戦（`npm run simulate`）で「ゲーム体験」の指標を測りながら、ルール・カード・AI・UIを調整した記録。

## 目標とした指標
| 指標 | 目安 | 意味 |
|---|---|---|
| 先攻勝率 | 50%±4 | 先攻・後攻の公平さ |
| デッキ相性 | どの組み合わせも40〜60% | どのデッキを選んでも勝負になる |
| 平均ターン数 | 各自8〜11ターン | 長すぎず短すぎない |
| 接戦率（勝者ライフ≤5） | 25%以上 | 最後まで勝敗が分からない |
| 逆転率（中盤劣勢側の勝利） | 30〜50% | 不利でも諦めなくてよい |
| 実力差の反映 | 評価型AIがランダムAIにほぼ全勝 | 運だけで決まらない |

## 最終結果（1800戦：3デッキ×3デッキ×200戦）
| 指標 | 結果 |
|---|---|
| 先攻勝率 | **51.8%** |
| 平均ターン数（各自） | **9.1**（ほとんどが7〜11ターン） |
| 接戦（勝者ライフ≤5） | **30.6%** |
| 圧勝（勝者ライフ≥15） | 14.4% |
| 逆転勝ち | **45.1%** |
| リード交代 | 1.54回/試合 |
| 対応カードの使用 | 1.68回/試合 |
| 未決着・引き分け | 0 |

デッキ相性（行のデッキの勝率）：
| | 疾風 | 城塞 | 均衡 |
|---|---:|---:|---:|
| 疾風（速攻型） | 49% | 53% | 49% |
| 城塞（防御型） | 48% | 49% | 51% |
| 均衡（標準型） | 51% | 53% | 57% |

実力差の反映（`node scripts/skill-check.js`）：
- 評価型AI vs ランダムに動くAI：**100%**（150戦）→ 運ゲーではない
- CPU「ふつう」vs「やさしい」：**74.7%** → 難易度に差がある

## 調整の経緯
| 段階 | 問題 | 対処 | 結果 |
|---|---|---|---|
| 1 | カードが少なく単調 | キーワード（飛行・先制・警戒）、一時強化、全体除去、召喚時に対象を選ぶ効果を追加し18種に。構築済みデッキ3種 | — |
| 2 | 先攻勝率 **67%** | 後攻に「マナの雫」（0コスト：マナ+1）。AIが使い道を判断できなかったので「次の1枚と組で評価」する処理を追加 | 54% |
| 3 | 先攻勝率まだ高め | マナの雫に「1枚引く」を追加 | **52%** |
| 4 | 速攻デッキが **13〜27%** と弱すぎ（ダメージがターン終了時に消えるため、硬い壁で止まる） | 岩の巨人 3/6→2/6、番犬の騎士 3/4→3/3、古竜 6コスト5/5→7コスト6/6、森の斥候に速攻、迅雷の狼 2/1→3/1、嵐の鷹 2/2→3/2、新カード「鬨の声」「疾風の騎手」 | 46〜53% |
| 5 | 迎撃の矢が強すぎ（使用時勝率61%）、均衡デッキが強い | 迎撃の矢は「攻撃している」クリーチャーのみ対象（守り専用の対応カードに）、戦場の将軍 3/4→3/3、均衡デッキの古竜を1枚に | 全相性 47〜53% |

## AI
- 盤面評価（ライフ・クリーチャーの攻撃/HP/能力・手札）＋1手先読み。
- 攻撃は全組み合わせを、相手の予想ブロック込みで評価。ブロックは全割り当てを探索。対応は「使う/使わない」を比較。
- 相手の手札は見ない（先読み時に相手の手札を空にしている）。
- 「やさしい」は対応を半分見逃し、ブロックは簡易判断、攻撃は上位3候補からランダム。

## UI・遊びやすさ
- デッキ選択、CPUの強さ選択、遊び方パネル。
- 直前の出来事（CPUの行動、ダメージの発生源）をプロンプト欄に表示。ダメージ・召喚のあったカードを光らせる。
- ブロック時に「このままだと受けるダメージ」を表示（致死なら赤字）。飛行を止められないブロッカーは選べない。
- 一時強化は色付きで表示（「このターン+2/+2」）。キーワードはチップ表示＋マウスオーバーで説明。
- 「全員選択」ボタン、ゲーム終了時の「もう一度遊ぶ」。

## 見つけて直したバグ
- 公開用の1ファイル版で、UIとエンジンの同名関数（`findCreature`）が衝突し、CPUの手番で停止する問題。→ 改名し、ビルド時に名前の重複を検出してエラーにするようにした。

## 残っている課題・次の候補
- 「手札超過」がたまに起きる（城塞デッキ）。知識の泉の枚数で調整可能。
- AIは1手先読みなので、上級者には物足りない可能性。探索の深さを増やすのが次の手。
- 2人対戦（同じ画面）の手札隠し、アニメーションの強化、効果音。
- 人間によるプレイテストでの感触確認（指標は自動対戦のもの）。

## v0.3（プレイテストのフィードバック対応）
フィードバック：「火球が強すぎる」「CPUに全然勝てない」

| 変更 | 内容 |
|---|---|
| 火球 | コスト 2 → **3** |
| CPUの強さ | 3段階に。**やさしい（初期設定）**／ふつう（旧やさしい）／つよい（旧ふつう） |

「やさしい」は対応カードを使わない、カードを出し渋ることがある、ブロックを見逃すことがある、攻撃の判断が雑。

難易度間の勝率（`node scripts/skill-check.js`、各150戦）：
| 対戦 | 勝率 |
|---|---:|
| つよい vs ふつう | 72.0% |
| つよい vs やさしい | 98.7% |
| ふつう vs やさしい | 94.0% |

火球変更後のバランス（1800戦）：先攻勝率 49.2%、平均9.1ターン、接戦 31.2%、デッキ相性は平均して46〜54%。
