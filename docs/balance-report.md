# 自動テスト・調整レポート（v0.2）

AI同士の自動対戦（`npm run simulate`）で「ゲーム体験」の指標を測りながら、ルール・カード・AI・UIを調整した記録。

## 目標とした指標
| 指標 | 目安 | 意味 |
|---|---|---|
| 先攻勝率 | 50%±4 | 先攻・後攻の公平さ |
| デッキ相性 | どの組み合わせも40〜60% | どのデッキを選んでも勝負になる |
| 平均ターン数 | 各自8〜11ターン | 長すぎず短すぎない |
| 接戦率（勝者ライフ≤5） | 25%以上 | 最後まで勝敗が分からない |
| 逆転率（中盤劣勢側の勝利） | 30〜50% | 不利でも諦めなくてよい |
| 実力差の反映 | 評価型AIがランダムAIにほぼ全勝 | 運だけで決まらない |

## 最終結果（1800戦：3デッキ×3デッキ×200戦）
| 指標 | 結果 |
|---|---|
| 先攻勝率 | **51.8%** |
| 平均ターン数（各自） | **9.1**（ほとんどが7〜11ターン） |
| 接戦（勝者ライフ≤5） | **30.6%** |
| 圧勝（勝者ライフ≥15） | 14.4% |
| 逆転勝ち | **45.1%** |
| リード交代 | 1.54回/試合 |
| 対応カードの使用 | 1.68回/試合 |
| 未決着・引き分け | 0 |

デッキ相性（行のデッキの勝率）：
| | 疾風 | 城塞 | 均衡 |
|---|---:|---:|---:|
| 疾風（速攻型） | 49% | 53% | 49% |
| 城塞（防御型） | 48% | 49% | 51% |
| 均衡（標準型） | 51% | 53% | 57% |

実力差の反映（`node scripts/skill-check.js`）：
- 評価型AI vs ランダムに動くAI：**100%**（150戦）→ 運ゲーではない
- CPU「ふつう」vs「やさしい」：**74.7%** → 難易度に差がある

## 調整の経緯
| 段階 | 問題 | 対処 | 結果 |
|---|---|---|---|
| 1 | カードが少なく単調 | キーワード（飛行・先制・警戒）、一時強化、全体除去、召喚時に対象を選ぶ効果を追加し18種に。構築済みデッキ3種 | — |
| 2 | 先攻勝率 **67%** | 後攻に「マナの雫」（0コスト：マナ+1）。AIが使い道を判断できなかったので「次の1枚と組で評価」する処理を追加 | 54% |
| 3 | 先攻勝率まだ高め | マナの雫に「1枚引く」を追加 | **52%** |
| 4 | 速攻デッキが **13〜27%** と弱すぎ（ダメージがターン終了時に消えるため、硬い壁で止まる） | 岩の巨人 3/6→2/6、番犬の騎士 3/4→3/3、古竜 6コスト5/5→7コスト6/6、森の斥候に速攻、迅雷の狼 2/1→3/1、嵐の鷹 2/2→3/2、新カード「鬨の声」「疾風の騎手」 | 46〜53% |

## AI
- 盤面評価（ライフ・クリーチャーの攻撃/HP/能力・手札）＋1手先読み。
- 攻撃は全組み合わせを、相手の予想ブロック込みで評価。ブロックは全割り当てを探索。対応は「使う/使わない」を比較。
- 相手の手札は見ない（先読み時に相手の手札を空にしている）。
- 「やさしい」は対応を半分見逃し、ブロックは簡易判断、攻撃は上位3候補からランダム。

## UI・遊びやすさ
- デッキ選択、CPUの強さ選択、遊び方パネル。
- 直前の出来事（CPUの行動、ダメージの発生源）をプロンプト欄に表示。ダメージ・召喚のあったカードを光らせる。
- ブロック時に「このままだと受けるダメージ」を表示（致死なら赤字）。飛行を止められないブロッカーは選べない。
- 一時強化は色付きで表示（「このターン+2/+2」）。キーワードはチップ表示＋マウスオーバーで説明。
- 「全員選択」ボタン、ゲーム終了時の「もう一度遊ぶ」。

## 見つけて直したバグ
- 公開用の1ファイル版で、UIとエンジンの同名関数（`findCreature`）が衝突し、CPUの手番で停止する問題。→ 改名し、ビルド時に名前の重複を検出してエラーにするようにした。

## 残っている課題・次の候補
- 「手札超過」がたまに起きる（城塞デッキ）。知識の泉の枚数で調整可能。
- AIは1手先読みなので、上級者には物足りない可能性。探索の深さを増やすのが次の手。
- 2人対戦（同じ画面）の手札隠し、アニメーションの強化、効果音。
- 人間によるプレイテストでの感触確認（指標は自動対戦のもの）。

## v0.4（カード拡張：約2倍、キーワード5種追加）

新キーワード：**吸命**（与えたダメージぶん回復）、**必殺**（ダメージを与えたクリーチャーを破壊）、**蹂躙**（余剰ダメージが貫通）、**加護**（1回だけダメージ無効）、**遺志**（破壊時に効果）。
新効果：ライフ回復、相手プレイヤーへのダメージ、トークン呼び出し、行動済みにする、破壊、加護付与、手札に戻す。
カード：デッキ用 20種 → **42種**（＋トークン2種）。デッキ：4つ目「冥夜（遺志・吸命型）」を追加。

### 調整の経緯（AI同士の総当たり）
| 問題 | 対処 |
|---|---|
| 速攻デッキが標準・冥夜に 2〜7% | 雷の槍 3→2ダメージ、誓いの聖騎士 4→5コスト、影の暗殺者 4→3コスト・HP2→1、回復量を減らす（修道女 3→2、祈り 5→4） |
| 冥夜が受けたダメージをほぼ全部回復（吸命が強すぎ） | 吸血公の召喚時全体ダメージを削除し 4/4 に、夜霧の蝙蝠 2/1→1/2、誓いの聖騎士は加護を外し 3/4 |
| 速攻の1HPクリーチャーが小さな除去で全滅 | 森の斥候 2/1→2/2、迅雷の狼 3/1→3/2、疾風の騎手 3/2→3/3 |
| 冥夜の安い遺志クリーチャーが交換で常に得をする | 墓守の老人 2→3コスト、デッキ構成を調整 |

### 結果（16組 × 150戦 = 2400戦）
先攻勝率 50.5%、平均9.8ターン、接戦 24.6%、逆転 41.5%。
デッキ相性（先後を平均）：疾風vs城塞 60%、疾風vs均衡 56%、疾風vs冥夜 35%、城塞vs均衡 44%、城塞vs冥夜 43%、均衡vs冥夜 47%。
（冥夜は速攻に強く、速攻は城塞に強い、という相性の傾向がある）

### ライフ上限の撤廃
回復・吸命でライフが初期値（20）を超えて増えるように変更（`lifeCap: null`。数値を入れれば上限を戻せる）。
変更後（1920戦）：先攻勝率 50.6%、平均9.9ターン。デッキ相性（先後平均）：疾風vs冥夜 34%、城塞vs冥夜 44%、均衡vs冥夜 48%（冥夜がわずかに強くなったが範囲内）。

## v0.5（瞬発を中心にしたデザイン）

### ルール変更
- 瞬発の機会を3回に：**攻撃宣言の後（防御側）**、**ブロック宣言の後（攻撃側→防御側）**。
- 1回の機会で、マナが続く限り瞬発カードを**何枚でも**使える（相手の瞬発への割り込みはなし）。
- **構え**：相手のターン中に使う瞬発カードはコスト−1（`quickDiscount`）。
- **瞬発クリーチャー**：相手の攻撃に合わせて呼び出し、そのままブロックに使える。
- 雷の槍を瞬発に変更。
- 断罪の剣を大胆な効果に：6コスト・レジェンド「場のクリーチャーをすべて破壊する（自分の側も、加護も無視）」。

### 追加カード（6種）と5つ目のデッキ「影刃（瞬発型）」
伏兵の槍兵（2/2/3・瞬発）、夜番の梟（3/2/3・瞬発・天翔）、闇潜みの刺客（3/2/2・瞬発・必殺）、
返し刃（1・瞬発：+3/+0）、見切り（2・瞬発：攻撃中の相手を手札に戻す）、霧隠れ（1・瞬発：味方を手札に戻す）。

AIは「瞬発カードを使えるだけのマナを残す」ことに価値を置くようにした（`quickReserve`）。

### 結果（25組 × 100戦）
先攻勝率 49.9%、平均9.6ターン、瞬発の使用 3.85回/試合（v0.4は約1回）。
デッキ相性（先後平均）はすべて 32〜57%。影刃（瞬発型）は他の4デッキに対して平均約52%。

## v0.6（デッキ見直し・演出・効果音）

### デッキの見直し（新カードを各デッキに配分）
- **疾風**：爆ぜる小鬼・群れの長を抜き、鉄槌の戦士2・返し刃3・足止めの網2に。攻めの最中に瞬発の+3/+0で相手のブロックや瞬発に打ち勝つ。
- **城塞**：盾持ちの兵1を伏兵の槍兵1に、知識の泉1を見切り1に。守りの瞬発を少し持たせた。
- **均衡**：見習い剣士1を夜番の梟1に。
- **冥夜**：変更なし（守護の祝福・送還の風が噛み合っており、霧隠れに替えると弱くなった）。
- **影刃**：見習い剣士を闇潜みの刺客の3枚目に。
- 霧隠れ（自分のクリーチャーを手札に戻す）はAIが上手く使えず、どのデッキでも勝率を下げたので構築済みデッキには入れていない。

### 結果（25組 × 150戦 = 3750戦）
先攻勝率 47.5%、平均9.4ターン、瞬発の使用 4.14回/試合。
各デッキの平均勝率（対他デッキ、先後平均）：疾風 約44%、城塞 約49%、均衡 約56%、冥夜 約51%、影刃 約49%。
もっとも偏った相性は 影刃→疾風（約70%）と 均衡→城塞（約63%）。速攻を瞬発で切り返す影刃は、疾風の天敵という位置づけ。

### CPUのブロック判断の修正（v0.6.1）
- 「やさしい」は一定確率でブロックを見逃すが、見逃すと負ける場面では必ずブロックするようにした。
- 「つよい」はブロックの候補を、戦闘ダメージを解決した後の盤面で比較するようにした（瞬発の機会が挟まると、ダメージ前の盤面で評価していた）。
- 簡易判断（ふつう・先読み用）は蹂躙のはみ出しダメージを計算に入れ、致死を防げるブロッカーを選ぶようにした。
- CPUが正しく守るようになり、試合が長く（各自 9.4→10.6ターン）、疾風（速攻型）が大きく弱くなった（影刃に約15%）ため、疾風専用カードを強化：
  嵐の鷹 3/2→**3/3**、鬨の声 +2/+0→**+2/+1**。
- 結果（25組×100戦）：疾風の平均勝率 約44%（城塞に約62%、冥夜に約29%、影刃に約36%）。先攻勝率は 42.9% と後攻有利寄り。

### 場の上限（5体）をなくした場合の試算
`boardLimit: 99` で同条件の対戦を比較：先攻勝率・平均ターン・決着率はほぼ同じ（引き分けや未決着も増えない）。
一方、6体以上が並ぶ場面は試合の約61%で一度は起こる（ターン単位では約5%、最大14体）。
バランスへの影響は小さいが、スマホでは場が2段以上に折り返して縦に長くなる・ブロックの組み合わせが増えてCPUの判断が簡易判断に切り替わる、という画面・AI側の対応が必要になる。

## 先攻・後攻の補正の見直し（v0.6.2）
CPUの守りの修正後、試合が長くなり **先攻勝率 42.9%**（後攻が約57%勝つ）と後攻有利になった。
「マナの雫」をなくし、別の補正を比較（各2500戦、先攻勝率）：

| 補正（マナの雫なし） | 先攻勝率 |
|---|---|
| 補正なし | 56.9% |
| 先攻の手札3枚（後攻5枚） | 46.4% |
| 先攻は1ターン目に引かない | 46.5% |
| 後攻の手札6枚 | 49.4% |
| 後攻のライフ +2 | 52.6% |
| **後攻のライフ +3** | **50.2%** |
| 後攻のライフ +5 | 46.4% |

**後攻のライフ +3（23で開始）** を採用。手札の枚数（仕様書の値）を変えずに済み、逆転勝ち 43.5%→49.2%、リード交代 1.57→1.82回/試合と、試合の競り合いも増えた。

### ライフ補正の撤回と、マナの増え方の検討（v0.6.3）
ライフは変えない方針になったため後攻ライフ+3は撤回（現状は補正なし、先攻勝率 56.9%）。
「毎ターン最大マナ+2、先攻の1ターン目だけ+1」の案を試算（各2500戦）：

| 案 | 先攻勝率 |
|---|---|
| +2ずつ・上限10・カードそのまま | 46.5%（5ターン目で上限、デッキ相性が極端） |
| +2ずつ・上限20・コスト全部2倍（全部偶数） | 33〜40%（後攻がぴったり使い切れて強すぎる） |
| +2ずつ・上限20・コスト2倍、約半分を1少ない奇数に | 45.9% |
| 同上、最初の手札を両者4枚 | 54.1% |

コストの奇数・偶数の配分で50%に合わせ込める見込み。全カードのコスト見直しが必要なため、方針確認待ち。

## v0.7 マナ2ずつ・奇数／偶数のコスト設計
- ルール：毎ターン最大マナ+2（先攻の1ターン目だけ+1）、上限20。先攻は奇数、後攻は偶数のマナで戦う。後攻への補正（マナの雫・ライフ）はなし。
- 全カードのコストを作り直し：旧コスト c を **2c−1（奇数・先攻向き）** か **2c（偶数・後攻向き）** に振り分けた。
  軽い速攻・妨害・瞬発の多くを奇数、強力な大型や効率の良いカードを偶数に寄せた。
  例：森の斥候 2、迅雷の狼 3、鉄槌の戦士 5、疾風の騎手 6、戦場の将軍 10、古竜 13、巨獣ベヒモス 15。
- 調整：冥夜が強すぎたため 不死鳥 9→10、誓いの聖騎士 9→10、墓守の老人 5→6、吸血公 11→12、癒しの祈り 5→6。
  影刃が弱かったため 闇潜みの刺客 6→5、伏兵の槍兵 4→3、見切り 4→3、番犬の騎士 8→7。
- 瞬発の軽減（相手ターン中 −1）はそのまま。偶数コストの瞬発は、相手ターンには奇数になる。
- AIの判断基準（引き直し・コストの評価）もコスト2倍に合わせた。

### 結果（25組 × 150戦 = 3750戦）
先攻勝率 **47.8%**、平均10.9ターン（従来とほぼ同じ長さ）、瞬発の使用 5.3回/試合。
デッキ相性はおおむね 35〜65%。冥夜がやや強く（平均約57%）、疾風がやや弱い（平均約45%）。

### 影刃の強化（v0.7.1）
- 瞬発の軽減（相手ターン中 −1）は据え置き（−2 はやりすぎ）。
- 夜番の梟 6→**5**、闇潜みの刺客 2/2→**3/2**。
- 影刃の構成：番犬の騎士2 → 毒刃の剣士2、迎撃の矢3→2、知識の泉1を追加。
- 疾風が影刃に約25%まで落ちたため、疾風の騎手 6→**5**。
- 結果（3750戦）：先攻勝率 47.3%。各デッキの平均勝率：疾風 約46%、城塞 約51%、均衡 約45%、冥夜 約54%、影刃 約55%。
  影刃は疾風に強く（約72%）、城塞に弱い（約40%）。

### 影刃を「人が使って」強く（v0.7.2）
CPU同士では影刃は平均約55%で弱くなかったが、人が使うと弱いという声を受け、使いどころを選びすぎる点を直した。
- 迎撃の矢：攻撃中の相手だけ → **相手のクリーチャーならいつでも2ダメージ、攻撃中なら3ダメージ**（相手が攻めてこなくても腐らない）。
- 城塞は迎撃の矢 3→1枚（盾持ちの兵・知識の泉を1枚ずつ追加）。矢の強化で城塞が強くなりすぎたため。
- 画面：自分のターン中、手札の瞬発カードに「相手番 X」（相手ターンに使うときのコスト）を表示。
  マナを残せば構えられるときは案内文で知らせ、相手のターン中は自分のマナの横に「構え」と出す。
- 試した案：伏兵の槍兵 3/3・夜番の梟 3/3 などの数値強化は、CPU同士で影刃が平均約65〜75%と強すぎたので見送り。
- 結果（3750戦）：先攻勝率 47.4%。影刃 約57%、城塞 約48%、疾風 約46%。

## デッキ構築とCPUデッキの変化（v0.8）
- 自作デッキ：30枚・同名3枚まで（validateDeck と同じ条件）。トークンとマナの雫は入れられない。
- CPUのデッキ：構築済みデッキを元に、6割の確率で2〜4枚を入れ替える（`arrangeDeck`）。入れ替え先は同じ種類（クリーチャー／呪文）でコスト±1のカード。
- 400戦で比較：入れ替えなし 41.5%、アレンジ版 42.8%（同じ組み合わせ・同じ席）。アレンジしてもCPUは弱くならない。

## v0.9 入れ替え・奪う効果と6つ目のデッキ「幻惑（トリック型）」
新カード6種：
| カード | コスト | 効果 |
|---|---|---|
| 鏡の反転（レジェンド） | 11 | 自分と相手のクリーチャーをすべて入れ替える（もらった側はこのターン攻撃できない） |
| 運命の交換（エピック） | 6 | 自分と相手の手札をすべて入れ替える |
| 心を操る者（エピック 3/3） | 12 | 召喚時：攻撃力4以下の相手クリーチャー1体を奪う |
| 入れ替えの道化（レア 2/3） | 5 | 召喚時：クリーチャー1体の攻撃力と体力を入れ替える |
| 影の掏摸（レア 1/2） | 3 | 召喚時：相手の手札からランダムに1枚奪う |
| 混沌の語り部（レア 2/4） | 4 | 召喚時：お互いにカードを2枚引く |

- 奪ったクリーチャーは自分のものになる（倒れたら自分の捨て札へ、手札に戻すと自分の手札へ）。
- AIの先読み：これまで相手の手札を空として扱っていたが、手札の入れ替え・奪う効果を評価できるよう「枚数は分かる、中身は平均的なカード」として扱うようにした。
- 結果（36組×100戦）：先攻勝率 48.7%。幻惑の平均勝率 約51%（冥夜に約73%、影刃に約39%）。新カードの使用時勝率は 49〜57%。
