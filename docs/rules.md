# 実装ルール整理（プロトタイプ v0.1）

仕様書 v0.3 をもとに、実装可能な形に整理したルール。
**【確定】** は確認済みのルール、**【仮】** の付いた項目は未確定のため仮置きしているもの（[open-questions.md](open-questions.md) 参照）。
数値はすべて `src/engine/config.js` で変更可能。

## 1. ゲーム開始
1. 各プレイヤーのデッキ（30枚・同名3枚まで）を検証する。
2. 先攻・後攻をランダムに決める。【確定】
3. 各デッキをシャッフルし、先攻は4枚、後攻は5枚引く。
4. 先攻→後攻の順に、1回だけ好きな枚数を引き直せる（マリガン）。戻したカードはデッキに混ぜ、同じ枚数を引く。【確定】
5. 先攻の第1ターンを開始する。

## 2. ターン進行
| フェイズ | 処理 | 備考 |
|---|---|---|
| 開始 | 最大マナ+1（上限10）→ 現在マナを最大まで回復 → 自分のクリーチャーの行動済み・召喚酔いを解除【確定】→ 開始時効果 | 自動 |
| ドロー | 1枚引く。先攻1ターン目も引く【確定】 | 自動 |
| メイン | カードを使う／攻撃宣言へ進む／ターン終了 | 手番プレイヤーが操作 |
| バトル | 攻撃宣言 → 防御側がブロック宣言 → 戦闘ダメージ | 攻撃しない場合はスキップ |
| エンド | 終了時効果 → **全クリーチャーのダメージを回復** → 相手のターンへ | 自動 |

- バトルフェイズ後にメインフェイズへは戻らない（戦闘後にカードは使えない）。【確定】
- 未使用マナは次の自分のターンには持ち越さない（ターン開始時に最大値まで回復）。ただし**相手のターン中は残っており、瞬発カードに使える**。【確定】

## 3. カードの使用
- メインフェイズに手番プレイヤーのみ使用可能。コスト分のマナを支払う。
- クリーチャー：場に5体いる場合は召喚不可。召喚したターンは攻撃不可（召喚酔い）。「速攻」持ちは攻撃可。
- スペル：対象が必要なものは合法な対象がいなければ使用不可。解決後は墓地へ。
- 召喚時効果は召喚直後に解決する。

## 4. 戦闘
1. 攻撃側は、攻撃可能なクリーチャーを**まとめて**宣言する。【確定：同時宣言方式】
   - 攻撃可能 = 行動済みでなく、召喚酔いでない（または速攻）。
   - 攻撃先は相手プレイヤーのみ（クリーチャーへの直接攻撃なし）。
   - 宣言したクリーチャーは行動済みになる。
2. **瞬発**：防御側が今使える「瞬発」カード（マナが足り、対象がいる）を持っていれば、1枚だけ使える（使わなくてもよい）。【確定】
   - 攻撃側は瞬発できない。瞬発への再瞬発もない。
   - 瞬発で攻撃クリーチャーが除去されたら、そのクリーチャーは戦闘から外れる。全員いなくなれば戦闘終了。
   - 使える瞬発カードがなければ確認は出さず、そのままブロック宣言へ。
3. 防御側はブロックを宣言する（しなくてもよい）。
   - 1体の攻撃につきブロッカー1体まで。1体のクリーチャーがブロックできるのは1体の攻撃のみ。
   - 行動済みのクリーチャーはブロックできない。【確定】
   - ブロックしたクリーチャーは行動済みになる。【確定】（自分のターン開始時に解除）
4. ダメージは全員同時に与える。
   - ブロックされなかった攻撃：攻撃力分を防御側プレイヤーへ。
   - ブロックされた攻撃：攻撃側と防御側が互いの攻撃力分を与え合う。超過分はプレイヤーに通らない。
5. 状態起因処理を行い、ターン終了へ。

## 5. ダメージと破壊
- クリーチャーが受けたダメージは**そのターンの間だけ**残り、ターン終了時に全回復する（MTG方式）。【変更：仕様書v0.3 §8の蓄積方式から】
  - 同じターン内なら「戦闘で3ダメージ＋火球で3ダメージ」のように合計して破壊できる。
  - `damageResetsAtTurnEnd: false` で仕様書v0.3の蓄積方式に戻せる。
- `ダメージ ≥ HP` になったクリーチャーは破壊され墓地へ。

## 6. 状態起因処理・勝敗
- カード使用後・戦闘後・各フェイズ処理後に、破壊判定と勝敗判定を行う。
- ライフ0以下のプレイヤーは敗北。両者同時に0以下なら引き分け。【確定】
- デッキが0枚でドローしようとした時点で敗北（通常ドロー・カード効果のドローとも）。【確定】
- 手札上限10枚。上限の状態で引いたカードは墓地へ。【確定】

## 7. キーワード
| 名前 | 効果 |
|---|---|
| 速攻 | 召喚したターンから攻撃できる。 |
| 天翔 | 天翔を持つクリーチャーでしかブロックできない。 |
| 先制攻撃 | 戦闘で、先制攻撃を持たないクリーチャーより先にダメージを与える。 |
| 番人 | 攻撃しても行動済みにならない（相手のターンにブロックできる）。 |
| 瞬発 | 相手の攻撃宣言後、ブロック宣言の前にも使える。 |
| 吸命 | このクリーチャーが与えたダメージと同じだけ、自分のライフを回復する（上限なし）。 |
| 必殺 | このクリーチャーからダメージを受けたクリーチャーは破壊される。 |
| 蹂躙 | 攻撃してブロックされても、ブロックしたクリーチャーを倒して余ったダメージを相手プレイヤーに与える。 |
| 加護 | 次に受けるダメージを1回だけ無効にする。 |
| 遺志 | 破壊されたときに効果が発動する。 |

## 8. 先攻・後攻の補正
- 後攻はマリガン後に「マナの雫」（0コスト、このターンのみマナ+1・1枚引く）を1枚受け取る。デッキには入れられない。
  - AI同士の計測で先攻勝率が約66%→約52%になった（docs/balance-report.md）。

## 10. 構築済みデッキ
| デッキ | 方針 |
|---|---|
| 疾風（速攻型） | 速攻と天翔、蹂躙で一気にライフを削る。 |
| 城塞（防御型） | 加護と除去で耐え、古竜とベヒモスで決める。 |
| 均衡（標準型） | 序盤から終盤まで満遍なく戦える。 |
| 冥夜（遺志・吸命型） | 倒れても力を残す遺志と、ライフを奪う吸命でじわじわ押し切る。 |

各デッキの内訳は `src/engine/cards.js` の `DECKS` を参照。
